**Category:** Projects / academic coursework

## Problem addressed
Classify cat and dog photographs with a pretrained convolutional feature extractor.

## Approach
InceptionV3-based transfer learning and image augmentation.

## Data and prerequisites
Notebook downloads an external cats-and-dogs archive and weights; includes Colab-style shell commands.
